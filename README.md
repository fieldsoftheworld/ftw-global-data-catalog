# ftw-global-data-catalog

Portolan/STAC catalog for the **Fields of the World (FTW) Global** datasets — **beta** release.

Catalog metadata lives in this repository; the data (field-boundary prediction COGs, GeoParquet,
PMTiles — ~26 TB) lives on [Source Cooperative](https://source.coop/ftw/global-data-beta) and is
never stored here.

**Status: bootstrap in progress.** See [docs/plan.md](docs/plan.md) for the build plan. The sibling
[ftw-data-catalog](https://github.com/fieldsoftheworld/ftw-data-catalog) repo holds the alpha
release catalog this one borrows from.
