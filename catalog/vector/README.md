# FTW Global (beta) — Vector field boundaries

Per-year collections of predicted agricultural field boundaries (2024, 2025): **254,714,908 parcels** total, as per-UTM-zone cloud-native GeoParquet. Part of [Fields of the World](https://fieldsofthe.world) — agricultural field boundaries delineated from Sentinel-2 imagery.

Browse it in the [data browser](https://source.coop/ftw/global-data-beta).

## Collections

- [2024](./2024/collection.json) — 120,455,491 parcels
- [2025](./2025/collection.json) — 134,259,417 parcels

New years drop in incrementally alongside these.
