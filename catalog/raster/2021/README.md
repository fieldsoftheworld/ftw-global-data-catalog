# FTW raster probabilities 2021

Field and boundary probability rasters for 2021: 14,584 COGs at 2.5 m, totaling 5,779,442,657,394 bytes. Each raster has two uint8 bands, field and boundary; probability equals pixel value / 255. Follow the 60 UTM-zone catalogs and their grid-zone catalogs to every item. Each item records its actual model checksum, four source mosaic IDs, projection, bounds and data destination. Field and boundary fractions are descriptive coarsest-overview measurements using uint8 >128 and >64; these are not vector extraction thresholds. Crop coverage preserves the uploaded RAILS index, using AWS 2024/2025 values where shared; the 26XNQ/27XVK r2 fallback lineage is producer-reported; 8 unknown fractions remain null. The STAC GeoParquet mirror contains the same item metadata for bulk queries.
