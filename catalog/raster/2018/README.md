# FTW raster probabilities 2018

Field and boundary probability rasters for 2018: 14,572 COGs at 2.5 m, totaling 5,773,163,860,769 bytes. Each raster has two uint8 bands, field and boundary; probability equals pixel value / 255. Follow the 60 UTM-zone catalogs and their grid-zone catalogs to every item. Each item records its actual model checksum, four source mosaic IDs, projection, bounds and data destination. Field and boundary fractions are descriptive coarsest-overview measurements using uint8 >128 and >64; these are not vector extraction thresholds. Crop coverage uses the fixed 2017/2020/2024 observations; 2 unknown fractions remain null. The STAC GeoParquet mirror contains the same item metadata for bulk queries.
