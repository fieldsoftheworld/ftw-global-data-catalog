# FTW raster probabilities 2020

Field and boundary probability rasters for 2020: 14,584 COGs at 2.5 m, totaling 5,741,839,617,973 bytes. Each raster has two uint8 bands, field and boundary; probability equals pixel value / 255. Follow the 60 UTM-zone catalogs and their grid-zone catalogs to every item. Each item records its actual model checksum, four source mosaic IDs, projection, bounds and data destination. Field and boundary fractions are descriptive coarsest-overview measurements using uint8 >128 and >64; these are not vector extraction thresholds. Crop coverage preserves the uploaded 2020 RAILS index without imputation; 0 unknown fractions remain null. The STAC GeoParquet mirror contains the same item metadata for bulk queries.
